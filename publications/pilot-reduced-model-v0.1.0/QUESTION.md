# Which actual matching-incidence axiom forces supplementation?

For abstract boundary supports with nonempty ParentKill, do endpoint, equality, and transpose consistency force a child bond incident to a new cell? The finite reduced model in RESULT.md answers no. What additional property of one actual complete perfect-matching family of a plane cubic brace excludes this support or forces the missing new-cell incidence?

Scope: distinguish abstract consistency from actual graph/matching realizability. This contribution does not ask whether the two-row object itself is a Barnette graph, and does not assert that the main conjecture is false.
